01  New authentication

One account for everything

Wattnet now has a single account. Sign in once and use the same identity in the developer portal, the API, the MCP server and the Python client. You manage your profile, your password and any third-party account you link in one place.

To call the API, create credentials in the developer portal. Each credential is yours: you can revoke it at any time, see how much it is used, and your access level applies to it.

If you had access to the API before, you should also have received a separate email with an invitation to create your account. Your access stays linked to it, so you keep what you had. If you cannot find it, check your spam folder.

Key date
The previous way to get a token, with your email and a password, keeps working until 28 February 2027. After that date it stops, so we recommend moving to credentials as soon as you can.
Open to everyone

Anyone can now create a free account. A new account starts at the Free level: a limited access, but enough to use Wattnet for the basics. When you need more, you can ask for the Research or Enterprise level from the developer portal.

02  API contract

A clearer, more complete API

We have refined the contract of the API. It is not a breaking change: everything you use today keeps working. We recommend moving to the new form because it is the one that will continue.

●points instead of values
Every series now carries points, with the timestamp, the value and updated_at. values is still returned and is removed after 28 February 2027.
●More control
Hourly or daily averages with resolution, a stable code in every error, and cached, compressed answers.
